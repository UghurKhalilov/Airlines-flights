# Airlines_flights
# ✈️ Airlines Flights Data Analysis

This project is a data analysis of airline flight data using Python.  
The goal is to explore flight patterns, ticket prices, routes, and airline performance using real-world datasets.

---

## 📊 Project Objectives

- Clean and preprocess airline dataset
- Analyze flight prices across airlines and routes
- Explore most and least expensive flights
- Study relationships between cities, airlines, and ticket prices
- Visualize insights using charts and graphs

---

## 🛠️ Technologies Used

- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook / Google Colab

---

## 📈 Key Analysis Performed

- Average and minimum flight prices per airline
- Most popular routes between cities
- Price comparison between airlines
- Flight duration and distance insights
- Data visualization using bar charts and plots
